# 自测、反馈与复习决策

## 先决定检测什么

对本次小目标形成轻量蓝图：知识点ID、预期动作（回忆/解释/鉴别/应用）、题目、关键评分点、来源。先准备可靠答案，再给学生题目；答案放在内部记录或单独答案文件。

优先混合少量开放式回忆和应用。入门者先简单回忆再解释，不强制一开始病例推理；学生要求选择题、口试、名词解释或考试题型时匹配。题目只覆盖已教内容；额外拓展明确标注并不计当前掌握。有效任务示例：

- “不看笔记，说出两个决定因素，并解释分别表示什么。”
- “在其他条件保持不变的简化情境，改变其中一项会怎样？”
- “这两个看似相近概念有什么一个关键区别？”

对同一个概念换问法，避免只是复现刚看到的原句。学生自述“知道了”或看着笔记作答，不算独立闭卷回忆。信心用低/中/高即可；没问则记录 unknown，不能替学生推断。

## 题目质量检查

医学单项选择题借鉴 NBME 命题原则，但不复制真实题库：问题清晰、存在一个可辩护的最佳答案、选项同类且相互区分、干扰项对应真实误解。遮住选项，题干仍应清楚地告诉学生要判断什么。避免通过答案长度、语法、重复关键词或“总是/从不”制造线索。

病例包含足够且必要的背景、阳性/阴性发现与适用条件。虚构病例注明虚构，不用人口属性代替实际证据，不把单一症状映射为唯一诊断。遇到两种答案都能成立、条件缺失或来源冲突时，不硬判学生错误：说明歧义、撤销计分并重写题。当前脚本不支持撤销已写入记录，故先完成题目审查和评分核对，再提交检测。

应用题应测试已学机制的迁移，而非突然要求未教过的临床指南。程序操作和沟通能力需监督下的真实/模拟练习；文本答题通过不能认证技能胜任。

## 对作答给可改进的反馈

按本题关键关系评分，接受医学意义相同的表述，不按参考答案逐字匹配。多目标题可分别给不同知识点记录：

| 结果 | 判据 | 反馈和动作 |
|---|---|---|
| wrong 错误 | 核心结论或关键因果错误；确实尝试回答“不会”也可记错误 | 点明错误，补前提或换示例，再问变式 |
| partial 部分 | 主方向正确但漏了预先确定的重要条件/关系 | 指出缺口，问一个聚焦问题 |
| hinted 需提示 | 看到答案、关键提示或笔记后才答对 | 记录提示；以后重新无提示检测 |
| correct 独立正确 | 未用提示，关键内容正确且能支持本题结论 | 反馈依据，随后做适度迁移或延迟复习 |

若回答错误且给了提示，则仍记 wrong；hinted 仅指借助提示后的正确。没答题、跳过、只阅读不填 result，可提交 `attempts: []` 记录学习。连错时减小块、降低提示门槛，不反复追问直到挫败。

反馈采用“你已对的部分 → 一个主要缺口 → 为什么错/依据 → 下一次怎样判断 → 一道修正验证”。将错误归到适合的类型：知识缺失、前提错误、机制断裂、相邻概念混淆、题意误读、条件/单位遗漏、推理证据不足。学生要求直接答案时可以给，不以教学规矩阻碍请求；后续作答记录已受提示。

## 到期复习和时间预算

新会话先读旧错误与到期队列，再决定今日新内容。把记录脚本 `due` 的清单转为1—3题的小轮次，答案仍隐藏。当前卡可能太长，先拆出一个可回答的问题；不要把队列当成命令要求学生完成全部。

初始时间配置可参考：

| 可用时间 | 今天实际做什么 |
|---|---|
| 10分钟 | 6分钟少量到期/旧错，2分钟修正验证，2分钟收尾；必要时一个小目标取代旧卡 |
| 25分钟 | 5分钟旧知识，10分钟一小块理解，7分钟回忆/应用，3分钟保存 |
| 50分钟 | 两个短学习循环，中间休息；按反馈决定第二块 |

这些比例是工作默认值，不是研究验证过的最优配方。脚本的分钟估计只用于选题，不能伪装为学生真实耗时。真实时长由学生报告或可用计时器获得；未知就在人工记录中写未知，脚本 `minutes` 只接受实际已确认的正整数。

连续独立成功指不同日期、当前内容版本的连续正确证据；错误、部分和提示正确会重置当前连续证据，历史仍在。`retained` 的最低门槛只是两个日期，不等于永久掌握，应说明间隔和证据范围。同日纠错后答对通常次日再问一次。

考前：依据明确范围和已知弱项缩小任务，优先核心误解、变式题与短复习。把长间隔的核心点在考前安排一次混合检测（仅提供建议或另记计划，脚本没有考试日期参数）。不承诺押题、成绩或通宵清空知识库。保留考后巩固建议。

大量积压：统计能读到的到期量和预算，先处理高信心错答及核心逾期，减少新卡，按可用时间渐进消化。无法取得旧卡内容时请求少量卡片或沿最近错误复习，不能虚构已完成数量或弱点排序。

## 周复盘

只对实际记录报告：投入时间（确认过的）、作答次数及分母、独立正确/提示正确、不同日期回忆证据、高信心错误、覆盖与未检测知识点、下周可执行调整。没有大纲就只报告知识库覆盖，不推算整门课程百分比。

用错因来改学习方式：机制断裂多就增加因果链和自解释；相邻概念混淆多就混合辨别；只会当天原题就增加延迟变式；积压增加就减少新卡和每次范围。学一周后的改进应体现在“隔天还能回答”，而非笔记页数。
