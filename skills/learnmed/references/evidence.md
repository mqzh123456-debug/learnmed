# 方法依据、借鉴与限制

检索/核对日期：2026-10-04。下面是设计依据，不是 learnmed 已经提高学习效果的实证。文献研究对象和结局不同；助手模拟与软件测试不能取代真实学生长期试用。没有下载、搬运或重发布教材及商业题库。

检索也发现影像教育等领域的较小综述。为避免把局部研究泛化到所有医学生，核心依据优先采用健康专业教育综述、原始教学试验和官方命题指南。研究支持的主要是学习策略；“最有效”的个人组合仍要通过延迟检测和实际时间投入来调整。

## 哪些是工程默认值

1—3题一轮、25分钟循环、每题约2分钟、核心/重要/拓展分级、1/3/7/14/30/60天初始间隔、两个不同日期判为 retained、包含一题应用判为 transfer-supported，都是**为可操作性设定的起点**。它们不是生理常数、验证过的测量量表、医学胜任力认证或个体化遗忘预测。技能应展示作答证据和实际间隔，让学生据此调整。

脚本没有 FSRS/SM-2、考试日期优化、课程总覆盖率预测或自动医学评分。长期保留与实际应用需要更长间隔和更丰富的任务来验证。用户自述信心帮助找出高信心错误，但不能独立判定掌握。

## 借鉴的 skill 工程方法

- 本环境的 **skill-creator**：入口只留改变决策的规则，模式细节按需加载；反复保存/计算交给可验证脚本。未复制其完整文案。
- **superpowers:writing-skills**：先观察无技能基线，再用实际场景检查行为。基线已能做好不少普通辅导，因此不把基线强行描述成失败。用验证支撑保存与继续学习的承诺。
- [Anthropic skill-creator](https://github.com/anthropics/skills/blob/main/skills/skill-creator/SKILL.md)：真实提示、行为比较与迭代。用独立测试观察工具输出及实际文件，减少作者仅凭自检的偏差。
- [Agent Skills 规范](https://agentskills.io/specification)：便于移植的 SKILL.md、脚本与参考资料结构。
- [OpenAI 的技能评估说明](https://developers.openai.com/blog/eval-skills)：在真实/隔离目录观察工作产物和失败，而非只凭技能文本判断好坏。

这些借鉴影响的是组织方式和验证方法。运行 learnmed 不需要安装上述技能，也不会自动创建子代理、联网或修改其他工具配置。

## 真实使用后怎样改进

试用一至两周后，对相同课程范围比较：延迟后的独立答题、旧错复发、完成一次学习的实际时长、复习积压以及记录负担。优先修正一个最常见的困难，再观察。没有匹配材料和难度的对照，不把变化归因于 skill；学生未坚持使用或记录太重时，先缩小范围与记录量。
