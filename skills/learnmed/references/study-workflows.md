# 导读、机制理解和知识梳理

## 导读先缩小范围

对章节/PDF先做轻量范围表：材料标识、实际可读范围、目录/图表、已读/本次处理/未处理。长文件按概念簇分段，不以已处理第一页冒充全章完成。跨页表格、图文关系和章节小结需回查上下文；工具提取有截断时写清未覆盖范围。

以本次学习目标选择材料，不逐句解释整章。先定位本节回答的问题、所需前提、主线和重要例外。初始优先级：

| 级别 | 判据 | 学生需要做到 |
|---|---|---|
| core 核心 | 已给课程目标；后续知识的必要前提；主干机制；重要鉴别与后果 | 闭卷说出并能解释关系 |
| important 重要 | 完善主干的条件、边界、常见易混点；材料明确要求的细节 | 解释何时适用，区分相邻概念 |
| extension 拓展 | 材料中的枝节、历史、罕见变型或超出当前阶段的深化 | 暂留索引；按课程要求再学 |

给每个选择附一句依据，如“本节反复使用这个关系，后面的调节机制依赖它”。学生已提供教师要求时覆盖通用排序。确实重要但超出今天预算的内容列到“下次”，不宣称可永久跳过。没有大纲就不给考试频率、押题概率或“必考”标签。

导读输出可仅用4行：本节问题；核心关系；今天能完成的学习结果；下一步读哪一小块。不要先制造另一篇长教材。

## 按认知困难选择教学动作

| 可观察的困难 | 选一个动作 | 检查有没有解决 |
|---|---|---|
| 术语不懂 | 一个定义、一个例子、一个反例，必要时附英文 | 学生用自己的话分类或解释 |
| 前提断层 | 补一个必要前提再回原问题 | 学生能接上缺失的关系 |
| 记得名词，不懂机制 | 让学生填因果链中的一环 | 能说明为什么，而非重复术语 |
| 两个疾病/药物混淆 | 沿同一维度做小对照，突出有判别力的一项 | 新描述中选出区别且解释依据 |
| 完全初学、连续失败 | 给一个完整示例，再给部分完成题 | 提示逐渐减少后仍能解释 |
| 看图不会 | 引导先定位、描述所见，再判断关系 | 能指出实际图像证据；无图不猜 |
| 只记住题目答案 | 改条件、改表述或换任务 | 新情境仍能独立应用 |

机制教学常用“条件/原因 → 分子或结构变化 → 功能变化 → 可观察结果”，箭头旁写关系，不把同时发生的两件事强行标成因果。学生熟练后减少示例与提示，避免把教学支架变成额外负担。

类比只用于搭桥，随后说明真实机制与类比的差异。口诀适合少量顺序/名词，但要回到含义、例外与适用条件，不能替代理解。

## 学科不同，结构也不同

- 解剖/组织：位置、毗邻、结构、功能、损伤后果；有原图时让学生做定位，不只背名单。
- 生理/生化：输入、过程、调控、输出；对定量关系注明条件、单位、近似与例外。
- 病理：病因、机制、形态、功能改变及表现，区分“相关”与“必然”。
- 药理：作用靶点、机制、用途、重要不良反应、禁忌/相互作用；具体剂量与现行临床用法需另行核验。
- 临床：问题表征、机制、支持/反对证据、鉴别、尚需信息。缺信息时保留多个解释，不以关键词单步确诊。

结构是整理工具，按教材内容选用，不要求每个知识点填写整套疾病表。

## 知识归纳应可累计

先让学生不看资料，用30—90秒写出主线。助手据材料和作答修补，优先选择最能解决今天困难的一个产物：因果链、3—5行小对照、概念层级或一条“为什么”解释。

归纳到已有库时查找同义名称和共同来源。复用原ID，把新标题当别名；只因措辞变化不要新增知识点。`related_ids` 链接前提、相邻概念或易混项，关系类型可在解释中写清。示例：基础概念“每搏量”成为“心输出量决定因素”的前提；不要把整个循环系统复制到每个条目。

冲突先定位来源/版本/适用条件，再决定修订或并列待核验。保留旧答案与旧作答的历史，最新已核验答案进入当前记录。自动工具只阻止同主题同名重复，不理解医学同义词；语义合并由助手核对，不能声称脚本自动去重全部知识。

学完后建卡只选值得重复提取的内容：一个清晰问题对应一个主要目标，答案通常1—3个要点，附来源。长段落、大而全的问题、答案未核验或上下文不足的卡先重写。机制卡保留因果，不拆成彼此孤立的词语。切忌为了“覆盖每一句”让复习量无限增长。
