# LearnMed 实际验证记录

日期：2026-10-04，Asia/Shanghai。场景均为自编教学材料，不包含真实学生、患者或商业题库资料。

## 验证做了什么

1. **无新技能基线**：独立助手完成一次初学20分钟开场，以及跳过检测、缺指定教材、答错、复习积压和同义笔记5个变化场景。
2. **带技能的独立辅导**：另一个助手读取入口和按需参考后，用相同初学材料生成首轮回应，再完成5个变化场景；不假造用户回答。
3. **可持久化的前向测试**：独立助手在私有、被Git忽略的隔离目录实际建立学习库、保存一次高信心错答，再从新Python进程读回。明确模拟2026-10-05的会话，只出题等待，没有编造第二天成绩。
4. **工具测试**：Python unittest 检查状态、日期、资料核验、预算、重试和文件完整性；真实CLI演示走完 init、upsert、record、次日 record、due 和 Anki TSV 导出。
5. **独立审查**：第三个助手执行代码与文档审查并复现两个重要缺陷；先补充失败测试，再修正并复测。

## 基线观察与带技能产物

基线已经能做到时间分配、说明学校重点未知、先教后测、缺来源时不编页码、限制10分钟任务，以及诚实说明没有保存工具。未把这些能力包装为“基线失败”。

基线的纯聊天接续卡可以保存来源、错误和明日问题，但简短卡片未系统保存原始题目、原始作答、提示、信心、稳定关系和版本。因此本技能的主要新增约束是可携带的证据合同与可运行的本地记录，而非声称仅靠增加提示词就改善所有教学行为。

带技能的首轮回应：

- 将材料明确标为自编示例S1、无页码；优先级不冒充校内高频考点。
- 给出20分钟的小目标和分步安排，只讲第一块后问一道题等待。
- 区分材料关系与补充类比，说明简化模型边界。
- 无文件能力时提供尚未完成的接续草稿，状态为未检测，未虚构作答、信心、实际时长或保存成功。

5个变化场景中，助手尊重不检测的选择并记录未检测，尊重指定30天日期并说明证据不足；拒绝编造指定页码；把10分钟积压任务缩小；说明工具不支持两个既有ID的merge；对双答案歧义题取消尚未写入的计分。输出经人工阅读，不是自动关键词评分。

前向文件测试实际保存：一次学习8分钟、原答“只有心率”、高信心、无提示、评分wrong、状态relearn、次日到期。次日新进程读到1次检测、1条到期旧错，输出不含答案的开场。只读查询前后文件SHA-256相同。没有创建真正的后台通知或Codex新聊天。

## 审查发现和修正

| 可复现问题 | 原来的后果 | 修正与回归检查 |
|---|---|---|
| 同ID更换来源覆盖旧出处 | 历史作答只能指向最新页码，未测过的旧答案丢失 | 旧来源/知识点版本归档，作答有不可变来源快照；检查原locator和旧答案仍在 |
| 修订后补记旧日期测验 | 旧答案错误计入新版回忆，甚至把下次日期倒退 | 当前版本带生效日期；拒绝生效日前检测，整批不写入 |
| Windows同步目录短暂占用目标文件 | 原子替换偶发PermissionError | 有限重试；持久失败保留原数据、清理临时文件和本次锁 |

前两项由独立审查复现；第三项在本机测试中间歇复现。修正都对应实际观察，没有把新产品功能混入修复。

独立复核重新执行原两个复现，确认旧来源和答案仍在，版本合并升级为2，旧日期检测拒绝且文件字节不变。还验证了单独修改来源、多个概念共享来源、未检测答案归档、标题/标签修改、无效整批更新、修订后正常作答与重试，未发现直接相关的重要回归。

## 软件与包检查结果

工具测试：**28项通过**。覆盖以下实际不变量：

- 阅读不提高掌握；未答题不算测验。
- 同日反复成功不当作延迟保持，提示正确不当独立成功。
- 新版本重新检测，旧内容和来源可追溯，旧日期不可套用新版。
- 同session重试不重复；冲突/未知来源/无效日期整批拒绝且旧文件不变。
- 预算内选择复习项，不暴露答案；高信心错答优先。
- 损坏文件不覆盖，初始化不清空旧库，并发锁不被偷偷移除。
- Anki HTML转义、换行与三字段输出正确；待核验卡不导出。

真实CLI演示得到 recalled → transfer-supported，2026-10-08到期；同输入重复提交不增加记录；导出TSV三字段。演示日期均显式模拟，不能当未来真实学习已完成。

本机 skill-creator 的 quick_validate.py 需要 PyYAML，但当前运行时未提供且安装未成功。因此没有将其报告为通过。改用仓库自带 tests/validate_package.py 核对本包采用的简单元数据布局、UI字符串、JSON和内部链接，并人工对照 Agent Skills 规范。这个检查器不是完整YAML解析器，也不能证明教学质量。

复现命令：

    python -m unittest discover -s tests -v
    python tests/validate_package.py

## 如何理解结果

这些是少量独立助手场景与确定性软件检查，不是大样本统计、5次重复的方差评估、医学内容权威认证或真实学生长期效果试验。evaluation-scenarios.json 是可继续复测的人工标准，列出场景不等于全部已取得正式通过评分。全部行为测试仍由作者审阅实际输出，没有自动凭关键词计分。

下一步适合在真实课程中连续使用一至两周，观察延迟独立回忆、旧错复发、实际耗时、积压和记录负担，再调整内容块、题量和复习建议。公开发布只包含通用技能、自编输入和验证说明；隔离测试的学习库不会进入仓库。
