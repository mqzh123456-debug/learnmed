# learnmed 验证计划

目标不是让 AI 输出更多，而是让学生在有限时间内完成可追溯的学习、检测和延迟复习。以下检查在发布前执行，结果见 evaluation-report.md。

- [x] 确认用户目标和目标仓库；新仓库无现有应用或教材需要迁移。
- [x] 阅读 skill-creator、writing-skills，以及公开的 Agent Skills 规范和技能评估设计。
- [x] 检索主动回忆、分散练习、医学教育认知负荷和医学命题资料。
- [x] 无新 skill 的独立模拟：初学20分钟、要求跳过检测、缺教材、错答、复习积压、重复笔记。
- [x] 写入口、按需参考文件、记录工具和可复现示例。
- [x] 记录工具先运行失败测试，再实现；验证重试、日期、成绩证据和文件完整性。
- [x] 使用新 skill 独立模拟实际学习，检查输出和生成文件。
- [x] 检查技能格式、内部链接、全部测试和个人资料隔离。
- [x] 提交到 learnmed；从远程读回核对（18个文件的Git blob哈希与本地源码一致）。

重点验收：无作答不提高掌握状态；提示后的正确不算独立回忆；重复提交不增加证据；同日练习不冒充延迟保持；来源不足不生成“教材重点”或未核验临床卡片；时间不足时复习队列可执行；没有写文件能力时诚实提供接续包；长期记录不上传到公开仓库。
